# Native uGUI batch action contract

`BeaverBatchUI` implements the `ui.*` action family for Unity 6000.6.2f1. It edits the supplied `GameObject` tree only; the batch transaction owns prefab contents, identity checks, saving, recovery, and variants. UI helpers never call `AssetDatabase.SaveAssets`. Paths are relative transform paths; an empty `path` or `targetNode` means the supplied root. Every referenced node and component must already exist unless the action explicitly adds one of the supported components below. The helper does not create or remove hierarchy nodes.

`numbers` must have exactly the documented number of finite values. Invalid or missing fields throw an action error; they are not silently replaced by defaults. For a prefab Variant, these actions may write supported serialized properties, persistent event overrides, or add a supported component to an existing node. They do not unpack, rewrite inherited children, or alter the base prefab.

| kind | Required fields and behavior |
| --- | --- |
| `ui.rect` | `path`; `numbers` is exactly `[anchorMin.x, anchorMin.y, anchorMax.x, anchorMax.y, pivot.x, pivot.y, anchoredPosition.x, anchoredPosition.y, sizeDelta.x, sizeDelta.y]`. Target must have `RectTransform`. |
| `ui.scroll` | `path` is an existing ScrollRect node; `targetNode` is its existing viewport (the host itself is allowed); `parent` is an existing content descendant of viewport; `mode` is `vertical` or `horizontal`. Adds `ScrollRect` to the scroll node and `RectMask2D` to viewport when absent, then assigns references and axis flags. Hierarchy is never synthesized. |
| `ui.grid` | `path`; `numbers` is `[cellWidth, cellHeight, spacingX, spacingY]`; `index` is a positive fixed column count. Adds or edits `GridLayoutGroup` with fixed-column constraint. |
| `ui.mask` | `path`; adds `RectMask2D` if absent. |
| `ui.text` | `path` must have a `TMP_Text`; `mode` is one of `overflow`, `truncate`, `ellipsis`, `masking`, or `scrollRect`; `property` is empty or `wrap`; when `property=wrap`, `flag` sets word wrapping. |
| `ui.event` | `path` has exactly one field named by `property`, whose value is a non-null zero-argument `UnityEvent`; `targetNode` (empty means root) has exactly one public instance method named `method` with zero parameters and `void` return. Optional `targetComponent` filters target MonoBehaviours by exact full type name; standard `Button.onClick` uses `property=m_OnClick`, while `targetComponent` names the existing callback controller. Private fields declared on base classes are included in field resolution. Adds a persistent UnityEventTools binding. Missing/ambiguous fields, multiple eligible methods, wrong signatures, and duplicate persistent bindings fail. No business stub is generated. |
| `ui.list` | Requires the installed runtime `Beaver.Tools.BeaverListView`; `path` is the list host; `parent` is the existing content RectTransform; `targetNode` is an existing, explicitly inactive item template anywhere under the host (inside or outside content); `property` is a relative child path inside the template whose node has `TMP_Text`; `items` is required and supplies row text (empty array clears only rows owned by this component). Adds the component to the host if absent. The inactive template does not participate in layout. Generated clones are activated after text is assigned. It does not remove authored children. |
| `ui.safeArea` | Requires the installed runtime `Beaver.Tools.BeaverSafeArea`; `path` is an existing `RectTransform` node with a RectTransform parent. Adds the component if absent. At runtime, maps all four screen safe-area corners into the parent RectTransform's local space, converts the resulting local bounds to normalized parent anchors, and sets zero offsets. This supports nested parent rects and is layout only. |

The two runtime source files must be explicitly installed by the batch caller under the user-selected runtime root, outside any `Editor` folder. `BeaverBatchUI` resolves their types at runtime, so batches that do not use `ui.list` or `ui.safeArea` compile without those runtime components. `BeaverListView` serialized contract: public fields `content`, `itemTemplate`, `textPath`, `items`; private serialized ownership list `generatedItems`; public read-only `OwnedCount` for runtime probes. Refresh deactivates each owned item immediately before scheduling its destruction, then creates and activates replacement rows. It destroys only objects recorded in `generatedItems` and leaves other content children alone. `BeaverSafeArea` has public `RefreshNow()` and no product/gameplay fields.

`Diagnostics(root)` reports static potential issues: zero-size RectTransforms, Buttons that are non-interactable or inactive in hierarchy, missing TMP font assets, and TMP overflow mode whose preferred width exceeds its RectTransform width. Unassigned Image Sprites and broken serialized object references are reported separately. An unassigned Image Sprite may be an intentional color panel and requires caller review; it is not automatically a missing-art failure. Scroll diagnostics also report missing references/masks, Raycast risks, and potential overlap by later opaque sibling Images. These diagnostics do not establish readable visual layout, a usable EventSystem/raycaster, real pointer or touch input, list behavior in Player, safe-area behavior on a device, or business correctness. Those require separate scene/Player/visual/input evidence.
