# Provenance and licenses

beaver is MIT licensed. Required upstream notices are distributed in `src/beaver/licenses/MONKEY-MIT.txt`, `src/beaver/licenses/GREA-MIT.txt` and [the third-party notice](MONKEY-THIRD-PARTY-NOTICES.md).

The adoption, candidate-manifest, bounded I/O and guarded transaction foundation was derived from the upstream monkey tooling. Imports, state roots, native companions and operation contracts were adapted to beaver. Source-package decoders and engine-emulation runtimes were not imported.

The reusable execution toolkit and selected Go example templates originated in GREA. Original toolkit IDs, report structures and exit codes remain compatible. The selected Go template's provenance manifest records upstream source digests; references to private handoff records are explicitly marked private. Go dependency licenses are described in the template's DEPENDENCIES.md and must be retained when redistributing compiled/vendor dependencies.

Native UI inspection, explicit repair/wiring planning, unified diagnostics and later bounded development operations are maintained in beaver. They use Python and Unity APIs plus explicitly declared optional providers. No Unity, Spine, Go, protocol compiler or third-party runtime binary is bundled.

Private reference materials informed requirements and controlled validation. Their archives, original projects, media, business configuration, user identities, environment settings, raw logs and private source inventories are not part of the distribution. Public provenance/validation JSON files are labeled summaries, not rewritten copies of private evidence. The original records are retained locally.

The first public Git history begins with the sanitized complete source snapshot. The earlier local development graph is preserved privately through named branches and a verified Git bundle; it is not claimed to be an ancestor of the public main branch.
