# UI inspection contract v1

`inspect(project, spec_path, output, editor, timeout=600)` performs read-only native collection over the exact selected `Assets/...` Prefab or Scene paths; `analyze(snapshot, spec)` is deterministic and does not infer visual or input success. Spec JSON requires `schemaVersion: 1`, an explicit `mode` (`static-prefab`, `static-scene`, `runtime`), and non-empty `assets`; optional `resources` lists explicitly selected imported asset paths for GUID/local ID subasset inventory, and optional `expectations` bind `asset`, `nodePath`, `componentType`, `field`, `equals`, and optional provenance `source`.

Snapshot root: `schemaVersion`, `mode`, `runtimeObserved`, `projectIdentity`, `assets`. Each asset has `path`, `guid`, `localId`, `type`, `sourceSha256`, `metaSha256`, `missingScripts`, `nodes` (including anchors, pivot, anchored position, size delta, rect, active states and sibling index), `components`, `events`, `overflow`, `missingGlyphs` (each row carries `glyphLookupStatus` and lookup errors when TMP APIs are unsupported), and runtime `hitTests`. Field rows also expose numeric `numbers` for Vector2/Vector3/Color properties. Each component has `nodePath`, `type`, `localId`, `assignableTypes`, `fields`, and `methods`. `fields` is an array of `{name, propertyPath, value, valueType, objectReference, referenceState, acceptedType, assignableTypes}`; references use `{guid, localId, type, nodePath, componentType}`. Event records use `{nodePath, componentType, field:'onClick', persistentCalls:[{target,method,mode,arguments}]}`. Methods expose `name`, `returnType`, `parameterTypes`, `public`, and `static`. Object references include `scope: node|asset|external`; node references use root-relative `nodePath` (scene roots include their GameObject names), asset references use GUID/local ID, and unresolved external references stay explicit. Findings include asset GUID/local ID, project identity, selected source/meta hashes and the observation/evidence basis. A missing reference is explicit (`referenceState:'missing'`); null is `null`, never conflated.

Collection and findings are static unless explicitly collected from a live runtime (`runtimeObserved:true`). Expected values are checked only against explicit spec rows with source provenance. Geometry, serialized references, glyph availability, and event metadata do not establish rendered visibility, unobscured appearance, a real pointer hit, or user-facing behavior. Runtime-dependent/conditionally hidden nodes are not errors by themselves. A playing Editor caller (`Application.isPlaying`) can use public `BeaverUIInspection.Collect(GameObject, label)` to obtain a JSON runtime snapshot. The runtime collector samples active and interactable Button centers with EventSystem.RaycastAll without invoking callbacks. Disabled or inactive buttons are marked skipped; missing EventSystem, Canvas, or required camera data yields unknown. A top hit outside the Button subtree is a blocked_hit candidate tied to the observed stage and raycast result; it may be an intentional overlay. This is not a physical click or visual acceptance. The native runner receives a UTF-8 job file through Beaver Base64 environment transport, exits with an explicit status, and reports Editor version and project source drift. `inspect` returns the saved report path and writes `ui-report.json` plus a hash-enriched `ui-snapshot.json`. `inspect` is batch/static-only and requires live runtime snapshots to enter through that caller. Unsupported serialized property shapes are reported as unknown/unsupported rather than guessed.
