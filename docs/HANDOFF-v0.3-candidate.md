# Legacy 0.3 compatibility

The earlier 0.3 candidate and its private validation records remain archived locally. They are not public release downloads.

Plans and transactions bind exact implementation/source identities. Preserve the original compatible provider when inspecting or recovering old transactions; a later version number does not authorize replay or silently rebind ownership.

The 0.5 release keeps the existing batch/production recovery and beaver-result contracts, including string/object actualChanges items and explicit postexecution consumer-schema failures. See [current contracts](CLI-CONTRACT.md) and [current validation boundaries](VALIDATION-v0.5.json).
