# Resource production

P03-B adds a closed Python plan contract and an Editor-only `Beaver.Tools.BeaverResourceProduction` companion. The caller must normalize each step with `validate_step`, obtain the exact read/write set from `declared_paths`, checkpoint it, install any independent image candidate through the transaction's explicit file-edit list, then call native `Apply` and `Verify`. The helper does not commit, install packages, run an Editor, call `AssetDatabase.SaveAssets`, or download dependencies. The only project-setting write is the separately declared `resource.project-settings` single-field operation below.

## Step contract

All paths are normalized project-relative `Assets/...` paths. Unknown fields reject. `declared_paths` returns sorted, concrete asset and `.meta` writes plus explicit source/consumer reads. Consumers use `{assetPath,nodePath,componentType,property,objectPath,objectName}`; binding support is limited to a direct object-reference field on a prefab component in an existing Prefab asset. The native helper obtains the expected reference type from that component's `SerializedProperty` field, walking base classes for inherited private fields, then requires a unique same-name asset object assignable to that type. Nested/array property paths reject. Ambiguous or missing targets report candidate types and local IDs. No wildcard, recursive search, or inferred consumer is added to the write set.

```python
validate_step(step) -> normalized_dict
declared_paths(project, step) -> {"reads": [str], "writes": [str]}
```

Supported step fields:

| kind | Required parameters / constraints |
| --- | --- |
| `resource.sprites` | Before declaring writes, the project must already resolve `com.unity.2d.sprite` in `Packages/manifest.json` or `packages-lock.json`, or provide a valid embedded `Packages/com.unity.2d.sprite/package.json`; otherwise preflight returns blocked `RESOURCE_SPRITE_PACKAGE_REQUIRED` before file edits. Existing `assetPath` TextureImporter; positive `pixelsPerUnit`; `maxSize`; explicit `alphaIsTransparency`; nonempty `slices` with unique `name`, stable 32-hex `spriteId`, pixel `rect`, 4-value `border`, normalized 2-value `pivot`; optional `fileId` means strict expected imported localID. Existing slices require their observed `fileId`, name and Sprite GUID to remain unchanged. New slices use `spriteId` as the identity source; Unity generates the native localID and Verify reports it. Deletion and identity churn are refused. |
| `resource.atlas` | `assetPath` must end in `.spriteatlasv2`; `spritePaths` are explicit existing project assets containing one or more Sprites; `includeInBuild`; `packing` declares nonnegative `padding` and booleans `tight`, `rotation`, `alphaDilation`; `pack` is mandatory, with explicit `buildTarget` when true. New V2 atlas authoring is additive and preserves previous packables. Apply never changes global Sprite Packer settings. With packing disabled, Verify returns `needs_action` without changing project settings. For `pack=true`, Verify repacks the loaded runtime Atlas for the declared target before reading packed Sprite clones, because this derived Library cache may not survive an Editor process restart. It does not edit Atlas authoring or source assets; count and exact canonical name-set checks remain required. |
| `resource.font` | Existing native `sourceFontPath`; `characterSet` is `texts` or `ascii` (ASCII plus the explicit text corpus); explicit `texts`, `samplingPointSize`, `atlasPadding`, `renderMode`, `atlasSize`, and `fallbackPaths`. `fallbackPaths` declares the complete direct fallback table, including any already present on an existing target font; undeclared fallback assets reject. These assets are bound before glyph generation. TMP source-font insertion may report missing characters without aborting while coverage is checked directly against the source font and each declared fallback font. This check uses `HasCharacter(character,false,false)` on each asset, so it neither recursively consults fallback assets that were not listed nor checks TMP project/global/default fallbacks. A Unicode character absent from all directly declared fonts fails with its code point. New TMP assets are created Dynamic, receive and verify glyphs, then switch to Static before the asset and all atlas/material subassets are saved. Existing Dynamic assets remain Dynamic. Existing Static assets switch temporarily to Dynamic only when needed and only if their recorded source-font GUID matches the declared source; their original Static mode is restored. DynamicOS or mismatched existing sources reject. Verification reports population mode, source GUID, atlas count, material path, exact fallback GUID set, missing glyphs and font GUID. |
| `resource.spine` | Existing skeleton asset at `assetPath`, explicit `runtimeVersion`, nonempty explicit atlas/page/material closure, and nonempty `animationNames`. Runtime types and `GetSkeletonData(false)`/`FindAnimation` are discovered and invoked by reflection. The loaded assembly's version must equal the request. Missing/mismatched runtime is a hard refusal; no vendor install or format repair occurs. |
| `resource.import` | Existing TextureImporter, AudioImporter, ModelImporter or Material, with nonempty scalar `settings` from a per-type allowlist. Material support only binds an explicit existing `shaderPath` asset; that path is included in the read set. No shader source is generated. |
| `resource.project-settings` | Exact field allowlist: `{kind, assetPath:"ProjectSettings/EditorSettings.asset", setting:"spritePackerMode", expectedValue, value}`. Only this existing file is declared read/write; there is no `.meta` write. `expectedValue` must match the live enum name before the setter runs. `value` and `expectedValue` must be exact names from Unity 6000.6.2f1's `SpritePackerMode`: `Disabled`, `AlwaysOn`, `AlwaysOnAtlas`, `BuildTimeOnly`, `BuildTimeOnlyAtlas`, `SpriteAtlasV2`, or `SpriteAtlasV2Build`. For the two V2 migration modes, Python write-set preflight and native Apply both block if any `Assets/**/*.spriteatlas` V1 asset exists; no migration contract is available. Apply resolves Unity's native `EditorSettings.GetEditorSettings()` singleton, checks the object maps to `ProjectSettings/EditorSettings.asset`, then synchronizes the public enum setter and `SerializedObject` field `m_SpritePackerMode` in memory. `VerifyBeforeExit` returns `pending_editor_reopen` only after live/static and serialized values match; it does not claim disk persistence. The batch owner must let Unity exit, then reopen the project and call strict `Verify`, which checks live getter, serialized field and on-disk enum. Restore reads the checkpoint enum and synchronizes only the in-memory setter/serialized field; the outer owner restores exact checkpoint bytes before Editor exit. The installed Unity 6000.6.2f1 metadata has no EditorSettings.Save/SaveProjectSettings method. `SaveAssetIfDirty` and raw serialized-file APIs were attempted and did not immediately persist this native project setting; they are no longer used here. No global `AssetDatabase.SaveAssets` or hand-written settings YAML is used. |
| `resource.serialized-asset` | Assertion-only native `.asset` contract: exact `assetType`, expected 32-hex `expectedGuid`, and nonempty exact `{property,guid,localId}` object-reference assertions. Python read/write declarations cover only the `.asset` and `.meta`; referenced object paths are not inferred or written and may be added to outer `readPaths` by GUID resolution. Apply checks class, target GUID and serialized reference GUID/localID without changing the reference values, then calls `SetDirty`/`SaveAssetIfDirty` only for that object. Verify force-imports the same asset and checks class, asset GUID and all requested object references again. This can prove a field rename preserved an existing SO reference after native save/reload; it does not prove unrelated fields or references unless they are explicitly listed. |

Each Sprite slice records its name, stable GUID, pixel rectangle, border and normalized pivot. Existing Sprites must declare their observed local fileID; new Sprites may omit it, and Verify reports the native ID generated by Unity.

`inspect_image(path)` provides read-only format/dimensions, byte size, alpha extent/counts, SHA-256 and decoded RGBA SHA-256. Python may produce a standalone PNG candidate with `produce_image(source, output, policy, expected_sha256)`. The caller supplies an explicit fresh output path; it must be outside the source directory tree, cannot overwrite an existing file or the source, and its path chain cannot contain symlinks. The helper has no working-directory or repository-root assumption. Modes are `lossless-png`, `resize-lanczos`, and `crop`. Lossless mode verifies decoded RGBA equality. Resize/crop require a numeric `maxLossPercent` and enforce that bound against removed source pixel area. Reports give the measured area reduction, the measured range, and the declared upper bound. This measures area reduction, not visual similarity; the implementation does not make a perceptual-quality claim. Source SHA is checked before and after. The output is never copied into `assetPath`; the outer transaction must stage and install it explicitly. JPEG/WEBP may be decoded as inputs but candidates are PNG. Animated/multiframe, compressed inputs over 256 MiB and images over 20 MP reject. Palette quantization, lossy encoding, color-profile conversion, generative repair and source in-place edits are unsupported.

## Verification evidence and limits

Native entry points are `Handles(string)`, `Apply(string,string)` and `Verify(string,string)`. Core `BeaverResourceProduction.cs` has no compile-time dependency on `UnityEditor.U2D.Sprites`. The transaction installs `BeaverResourceSprites.cs` only for a Sprite step after package preflight; this optional companion retains Unity Sprite Data Provider APIs and stable Sprite GUID/localID checks. Font/Atlas/import/Spine operations can compile without the optional Sprite Editor namespace reference. Sprite verification reads Unity's imported Sprite sub-assets and reports name, GUID, localID, rect, border and normalized pivot; it also reports Unity's original pixel-space pivot separately. Optional declared localIDs are checked exactly. The installed Unity 6000.6.2f1 `UnityEngine.CoreModule.xml` documents `SpriteAtlas.GetSprites` as cloning the packed Sprites. Atlas `pack=true` therefore reads raw clone names and maps each either to one exact source name or to that exact name with the fixed `(Clone)` suffix. Duplicate source names or ambiguous/unrecognized clone names fail closed instead of being normalized speculatively. Atlas V2 authoring is restricted to `.spriteatlasv2` paths and loaded through `SpriteAtlasAsset.Load(path)`; Verify reports the authoring asset name as the path basename and the runtime `SpriteAtlas.name` separately. Runtime packability/clone closure remains strictly read back from the runtime atlas. This is Editor target-pack evidence, not a Player build, runtime atlas load or proof of `includeInBuild` behavior. Verify returns `needs_action` when Sprite Packer mode is disabled. Font verification reports the observed asset name as well as source GUID, population mode, atlas/material children and requested corpus coverage. Font glyph coverage checks only `HasCharacter(character,false,false)` on the source and individually declared fallback assets. It never consults TMP global/default fallback lists or unlisted nested fallbacks, and it never mutates fallback assets or settings. Spine verification checks actual requested animation lookup and explicit dependency existence; it does not instantiate/play the component or claim rendering. Import verification reads back each declared scalar or Shader setting after importer reimport.

This subtask does not run Unity Editor or Player. The main integration owner must compile and execute the native companion in the supported project version, inspect transaction recovery, and run any required build/runtime acceptance. A successful standard-library test is contract-helper evidence only. Existing assets and raw game files are not copied into the Beaver distribution. GREA's pre-existing alpha-audit algorithm source was read at `tools/grea/src/grea/tools/image_alpha_audit.py` (SHA-256 `15e5037cba54e062c19ebd239e6813658f62c8cd8450d1466fa0be5837392b47`) and Unity native asset inspector at `tools/grea/src/grea/tools/unity_native_assets.py` (SHA-256 `7e641ea2c0fd1ab5d84c1f64b070dd20ab7c2afb245b7b06aedfd18a3e84529f`); only the existing alpha-audit approach informed image inspection. The registered GREA MIT notice remains in package licenses. Sprite APIs follow the Unity `sprite-editor` capability/provider model; SpriteAtlas authoring follows Unity's V2 `SpriteAtlasAsset`/`SpriteAtlasImporter` model; TMP glyph/fallback APIs follow Unity uGUI/TMP. Spine is reflection-only and requires the project's already-installed, licensed runtime; no runtime binary is copied or redistributed.

Private fixture resource records are not distributed. For a real target, obtain exact source GUIDs, subasset identities, importer/runtime versions and consumer fields from the selected project; never copy identifiers from an unrelated example.

## Unsupported / refused cases

There is no Sprite deletion/re-ID, automatic consumer discovery, image quantization, arbitrary external file import, multi-material shader graph editing, importer scripts, platform-specific audio codec conversion, Spine version migration, missing-runtime installation, skeleton re-export, or representative Spine playback. Unsupported Unity versions/API shapes fail closed. `Apply` mutates only its supplied project assets, declared prefab consumers, or the single exact project setting above; it never calls global `SaveAssets`. Recovery may call `RestoreProjectSettings(backupPath)`, which reads only `m_SpritePackerMode` from the supplied existing `EditorSettings.asset` backup and restores it through both `EditorSettings.spritePackerMode` and its `SerializedObject` property; both forward Apply and restore block V2 migration modes while any V1 atlas path remains. The root transaction owner restores exact checkpoint bytes after the in-memory Unity setting has been synchronized, then verifies after Editor reopen.
